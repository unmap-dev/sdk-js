# Runnable examples

Serve this directory with `python3 -m http.server 8080 --directory examples` from the repository
root and open http://localhost:8080. Each page is a complete HTML example, using the pinned
published browser SDK. Enter your own browser key, with http://localhost:8080 allowed on it.
The key is held only in the page while it is open; these pages do not save it.
